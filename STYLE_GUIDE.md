# Felix Brillant — GitHub Visual System

## Positioning
**Production AI Platform Engineer**

**Signature:** Engineering AI platforms that transform enterprise data into trusted operational decisions.

## Color Palette
| Token | Hex | Usage |
|---|---|---|
| Midnight | `#0B1220` | Primary background |
| Deep Navy | `#10233A` | Cards and panels |
| Azure | `#2EA8FF` | Primary accent |
| Sky | `#4CC2FF` | Secondary accent |
| Slate | `#9CA3AF` | Secondary text |
| White | `#FFFFFF` | Primary text |

## Typography
- Primary: Inter
- Fallback: Arial, sans-serif
- Headings: 700
- Labels: 600
- Body: 400–500

## Visual Rules
- Dark backgrounds only.
- 20–28 px card radius.
- 1–2 px thin outlines.
- No gradients outside banner and large diagrams.
- Use one icon family across all repositories.
- Maximum three technology tags per platform card.
- Detailed metrics stay in repository READMEs, not the profile README.

## Reuse
Apply this system to:
- GitHub profile README
- FlowPay README
- AWS CFO FinOps README
- QuantLab README
- Portfolio website
